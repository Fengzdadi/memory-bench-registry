# memory-bench-registry

结构化的 agent memory benchmark 登记库：每个 benchmark 一个 YAML（`benchmarks/<slug>.yaml`），本 README 由脚本生成。
所有字段都必须能在论文或官方仓库里找到出处（记录在各条目的 `sources` 中），找不到即为 `null`。

- 字段与可复现等级定义：[docs/fields.md](docs/fields.md)
- 现有汇总列表的覆盖缺口核对：[docs/coverage-gaps.md](docs/coverage-gaps.md)
- 现有汇总列表及其核实状态：[docs/related-lists.md](docs/related-lists.md)

当前共 **141** 条。可复现等级分布：`unverified` 0 · `paper_only` 21 · `data_public` 20 · `official_script` 100 · `smoke_tested` 0 · `full_run` 0
