### 可复现等级

| 等级 | 含义 |
| --- | --- |
| `unverified` | 还没有人打开论文和仓库核对 |
| `paper_only` | 核对过论文；找不到公开数据或代码 |
| `data_public` | 数据可公开获取，但官方仓库没有评测脚本 |
| `official_script` | 官方仓库有可直接跑评测的脚本，且数据可获取 |
| `smoke_tested` | 我们用官方脚本在小样本上跑通过 |
| `full_run` | 我们跑过完整评测 |

## 贡献

1. 新增 `benchmarks/<slug>.yaml`，按 [docs/fields.md](docs/fields.md) 填写，每个非空字段在 `sources` 中注明出处。
2. 运行 `python scripts/validate.py` 与 `python scripts/build_readme.py`。
3. 不要手改 README（中英文两份）；CI 会检查它们与数据是否同步。
